Offline-first edge fleet control plane for Linux, Kubernetes, containers and VMs. Declare desired state; agents reconcile it when the WAN disappears — no arbitrary remote shell.

Desired state

Control plane revisions with typed workloads: systemd, container, k3s and opt-in QEMU.

PULL2

Agent caches

fleet-agent pulls the full revision to local disk. Sites need no inbound management port.

RECONCILE3

Typed adapters

Validated unit names, images, manifests — drift is replaced, not ignored. No generic shell.

OFFLINE4

WAN goes dark

Cached revision stays authoritative. Adapters keep reconciling. Events queue on disk.

REPLAY5

WAN returns

Queued events replay on the next heartbeat. Newer revisions apply after catch-up.
